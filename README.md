# Fruit Slice 🍉

เกมฟันผลไม้สไตล์ Fruit Ninja ทำด้วย HTML/CSS/JavaScript ล้วน (ไม่ใช้ไลบรารีภายนอก)

## โครงสร้างโปรเจกต์
```
fruit-ninja/
├── index.html      โครงหน้าเว็บ, canvas, หน้าจอเริ่ม/จบเกม
├── css/
│   └── style.css   สไตล์และธีมภาพ (โต๊ะไม้, สีเลือด/ทอง, overlay)
└── js/
    └── game.js     ตรรกะเกมทั้งหมด: สุ่มผลไม้, ฟิสิกส์, ตรวจจับการฟัน, คะแนน, ชีวิต
```

## วิธีเล่น
ลากนิ้ว (มือถือ) หรือกดค้างแล้วลากเมาส์ (คอมพิวเตอร์) ผ่านผลไม้ที่ลอยขึ้นมาเพื่อฟันให้ขาด
ห้ามฟันโดนระเบิด 💣 ไม่งั้นเสียชีวิต ถ้าปล่อยผลไม้ตกพื้นก็เสียชีวิตเช่นกัน มี 3 ชีวิต

## วิธีรัน
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์โดยตรง หรือรันเซิร์ฟเวอร์ในเครื่อง เช่น
`python3 -m http.server` แล้วเข้า `http://localhost:8000`
